# RAAD (رعد) — Digital Wallet

MVP digital wallet on AWS: users sign in and send simulated Saudi Riyal (SAR) between RAAD wallets, with accurate balances, duplicate-transfer protection and a transfer history.

- **Requirements source:** [Statement of Work](aidlc/spaces/default/knowledge/documents/Raad-SOW.pdf)
- **Process:** built with [AI-DLC](https://awslabs.github.io/aidlc-workflows/). Design records and decisions are kept under `aidlc/`, and the framework is in `.claude/`.
